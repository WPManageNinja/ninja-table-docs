# WooCommerce Product Average Rating Column

The **Product Average Rating** column (Pro) shows a product's overall average score next to each individual review. Customers can see both at once — the single review (for example, 5 stars) and the product's average (for example, 4.5/5).

Add it to any [WooCommerce Product Reviews Table](/guide/data-sources/woocommerce-product-reviews-table).

## Add the Average Rating Column

- In the **Table Rows** section, click the **Add New Column** sub-tab.
- Configure the basic settings, such as **Column Name** (for example, "AVG. Rating") and **Data Type**.
- Scroll down to **Dynamic Column Data Settings**, which pulls data directly from your products.
- Select the product average rating as the field value.
- Click **Add Column** to save it.

![WooCommerce product average rating column](/images/data-sources/woocommerce-average-rating/1.-WooCommerce-product-average-rating.webp)

The table now shows the average rating in its own column.

If you would rather not build a separate review table, this column is a quick way to surface rating data inside an existing [WooCommerce table](/guide/data-sources/woocommerce-integration). The rest of the table's options are the standard Ninja Tables settings described in [WooCommerce Product Reviews Table](/guide/data-sources/woocommerce-product-reviews-table).
