# Create Custom Column in WP Post/CPT/WooCommerce Table

Ninja Tables can be synced with **WP Posts** and Pages. With the help of this feature, any post can be incorporated into your tables using Ninja Tables.

You can easily create custom columns or Custom Fields in the [WP Posts](/guide/data-sources/create-wp-posts-table) table, or even in [WooCommerce](/guide/data-sources/woocommerce-integration) tables by going through some easy steps.

## Add Column to WP_Posts Table/WooCommerce Tables

- Go to the **Add New Column** tab of a WP Posts table or WooCommerce product table.

- Scroll down & then you will get the **Dynamic Post Data Settings**. Choose your preferred Field type.

![Dynamic Post Data Settings](/images/wordpress-integration/create-custom-column-wp/1.-Add-Post-Table.webp)

You can also check out **[Post Meta](/guide/wordpress-integration/post-meta-field)**, **[Shortcode / Computed Value or HTML](/guide/wordpress-integration/shortcode-computed-value-or-html-in-wp-post-woocommerce-table)**, & **[Featured Image](/guide/wordpress-integration/featured-image)**.
