# Table Data Font Settings

From the **Table Font Settings** option in the "**Other" **tab, users can change the table's font family and font size according to their requirements.
It's way below in the following screenshot.
![New Ui table design Other tab](https://ninjatables.com/wp-content/uploads/2025/05/New-Ui-table-design-Other-tab-383x1024.webp)
- Users can choose the Font Family from the dropdown. The list has multiple fonts- Cursive, sans serif, monospace, etc.
- Users can set the font size manually in the Font Size input field.
Using Font Settings in data tables, you can stylize the texts. For example, a restaurant menu table can use cursive fonts to match the restaurant theme.
