Merging table cells horizontally (colspan) or vertically (rowspan) to combine adjacent cells into
one. Free when building in Drag & Drop mode; a Pro-only capability in Advanced/Classic mode. Per
the readme's Premium feature list line "Merge/split table cells (Free in Drag and Drop)".
