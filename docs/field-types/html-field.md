# HTML Field

The **HTML field** column type is for rich content: bold or colored text, lists, links, images and other media. You edit each cell with the WordPress editor, so you don't need to write HTML by hand.

## Set a column to HTML field

1. Go to **Tables** › your table › **Table Rows**.
2. To add a new column, click **Add column**. To change an existing one, click the gear icon on its header and choose **Column settings**.
3. In the **Basic** tab, set **Type** to **HTML field**.
4. Click **Add column** or **Save column**.

![Column type list](/images/field-types/html-field/1.-data-types.webp)

::: warning Only for trusted editors
HTML cells can hold links, media or any formatted content. Only people you trust should be able to edit this column.
:::

## Add content

HTML cells aren't edited inside the grid. Open the row drawer instead: click **Add data** for a new row, or the pencil icon (**Edit row**) on an existing row. The HTML column shows the WordPress editor, where you can format text, add links and insert media.

![HTML field in the row drawer](/images/field-types/html-field/2.-HTML-field-in-Ninja-Tables.webp)

Click **Add row** or **Update** to save. See [Working in Table Rows](/working-in-table-rows) for more about the drawer.
