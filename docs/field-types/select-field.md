# Select Field

The **Select field** column type (Pro) gives a column a fixed list of choices. Instead of typing, you pick a value from a dropdown when you edit a cell, so the values stay consistent. For example, *Yes* / *No*, or *In stock* / *Out of stock*. The same list is used by [Custom filters](/custom-filters).

On the free version, a Select field column works as plain text.

## Set a column to Select field

1. Go to **Tables** › your table › **Table Rows**.
2. To add a new column, click **Add column**. To change an existing one, click the gear icon on its header and choose **Column settings**.
3. In the **Basic** tab, set **Type** to **Select field**. The settings below appear.
4. Click **Add column** or **Save column**.

![Select field settings](/images/field-types/select-field/1.-Select-field-in-data-type.webp)

### Select items

Enter the choices, one per line. For example:

```
Yes
No
```

### Placeholder

Text shown in the dropdown before a choice is made, for example *Choose a plan*.

### Enable multi-selection

Tick **Enable multi-selection** to allow more than one choice in a cell, for example both *Yes* and *No*.

## Fill in the column

Click a cell in the Table Rows grid, or open the row drawer, and pick a value from the dropdown.
