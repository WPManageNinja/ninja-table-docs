# How to Install Ninja Charts

Charts in Ninja Tables come from **Ninja Charts**, a separate free plugin. It reads the tables you already have, so there is nothing to re-enter. It needs WordPress 6.3.1 or later and PHP 7.4 or later.

## Install from Ninja Tables (one click)

1. Go to **Ninja Tables** › **Charts**.
2. The page shows "Ninja Charts is not installed yet". Click **Install Ninja Charts**.

Ninja Tables downloads, installs and activates Ninja Charts, then opens the chart list. Your user needs permission to install plugins (administrators have it).

Once Ninja Charts is active, **Ninja Tables** › **Charts** opens the chart list, and an **Add Chart** item appears in the Ninja Tables menu.

## Install from the Plugins screen

![Install and activate Ninja Charts](/images/ninja-charts/install-ninja-charts/1.-Install-activate-ninja-chart-01.webp)

1. Go to **Plugins** › **Add New Plugin** in WordPress.
2. Search for "Ninja Charts", click **Install Now**, then **Activate**.

Or download the `.zip` file from WordPress.org and upload it with **Upload Plugin** on the same screen.

## Update Ninja Charts

Ninja Charts updates like any other plugin: when an update is available, click **Update** on the **Plugins** screen or in **Dashboard** › **Updates**.
