# Ninja Tables Free vs Pro

The free **Ninja Tables** plugin covers everything you need to build, style and publish tables. **Ninja Tables Pro** is an add-on that adds live data sources, more column types, extra design options and tools such as custom filters and frontend editing. This page lists what's in each, so you can tell at a glance whether a feature needs Pro.

In the plugin, Pro features show a **Pro** badge or a lock until Pro is active. To upgrade, see [Upgrade and activate your Pro license](/upgrade-to-ninja-tables-pro-add-on-and-activate-ninja-tables-pro-license-key).
