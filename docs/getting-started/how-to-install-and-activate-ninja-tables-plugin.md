# How to Install and Activate Ninja Tables Plugin

**Ninja Tables** installs like any other WordPress plugin. The free plugin is required even if you use Ninja Tables Pro, because Pro is an add-on that runs on top of it.

## Requirements

- WordPress 6.0 or higher (tested up to WordPress 7.1)
- PHP 7.4 or higher

## Install from the WordPress dashboard

1. In your WordPress admin, go to **Plugins** › **Add New**.
2. Search for **Ninja Tables**.
3. Click **Install Now**, then **Activate**.

![Install and activate Ninja Tables](/images/getting-started/install-activate-ninja/1.-Install-and-activate-Ninja-Tables-1.webp)

## Install from a .zip file

1. Download the plugin .zip file from the [WordPress plugin directory](https://wordpress.org/plugins/ninja-tables/).
2. In your WordPress admin, go to **Plugins** › **Add New** › **Upload Plugin**.
3. Click **Choose File**, select the .zip file and click **Install Now**.
4. Click **Activate Plugin**.

![Install and activate Ninja Tables by uploading .zip](/images/getting-started/install-activate-ninja/2.-Install-and-activate-Ninja-Tables-by-upl.webp)

## After activation

Click **Ninja Tables** in the WordPress admin menu. Because you have no tables yet, you'll see the **Welcome to Ninja Tables** screen. Click **Create your first table** to start, or **Import table** if you already have your data in a file.

Next, follow the [quick start guide](/onboarding-setup-guide) to build and publish your first table. To unlock the Pro features, see [Upgrade and activate your Pro license](/upgrade-to-ninja-tables-pro-add-on-and-activate-ninja-tables-pro-license-key).
