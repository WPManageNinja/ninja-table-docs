# How to Install and Activate Ninja Tables Plugin

**Ninja Tables** installs like any other WordPress plugin. The free plugin is required even if you use Ninja Tables Pro, because Pro is an add-on that runs on top of it.

## Requirements

- WordPress 6.0 or higher (tested up to WordPress 7.1)
- PHP 7.4 or higher

## Install from the WordPress dashboard

1. In your WordPress admin, go to **Plugins** › **Add New**.
2. Search for **Ninja Tables**.
3. Click **Install Now**, then **Activate**.

## Install from a .zip file

1. Download the plugin .zip file from the [WordPress plugin directory](https://wordpress.org/plugins/ninja-tables/).
2. In your WordPress admin, go to **Plugins** › **Add New** › **Upload Plugin**.
3. Click **Choose File**, select the .zip file and click **Install Now**.
4. Click **Activate Plugin**.

## After activation

Activation doesn't redirect you anywhere. Click **Ninja Tables** in the WordPress admin menu to open the plugin. The menu also has **Tables**, **Create Table**, **Import**, **Charts**, **Settings** and **Help**.

Because you have no tables yet, Ninja Tables opens a two-step **guided setup**. Pick how you want to start (a blank table, a file, a data source or a Drag & Drop table), then finish the table in step 2. To skip it, click **Skip setup**; you land on a plain screen with **Create a table** and **Import** buttons instead. See [Onboarding](/guide/getting-started/ninja-tables-onboarding).
