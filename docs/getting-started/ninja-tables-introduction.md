## Where things live in the plugin

Every Ninja Tables screen shares one top bar. Inside a table, the editor has six tabs.

![Ninja Tables top bar with numbered badges: 1 Tables, 2 Create Table, 3 Import, 4 Charts, 5 Help, 6 gear icon for Settings, 7 theme icon](/images/getting-started/ninja-tables-introduction/1.-Top-Bar-Numbered.webp)

1. **Tables**: the [list of all your tables](/tables-list), with each table's shortcode.
2. **Create Table**: pick what kind of table to build.
3. **Import**: create a table from a CSV, Excel or JSON file, or from TablePress.
4. **Charts**: turn table data into charts with the free [Ninja Charts](/getting-started-with-ninja-charts-free-wordpress-chart-plugin) plugin.
5. **Help**: documentation, support and community links.
6. The gear icon › **Settings**: **General**, **Global appearance**, **Permissions** (Pro), **Performance** and, once Pro is active, **License**.
7. The theme icon: switch the admin between **Light**, **Dark** and **System**.

Press <kbd>⌘</kbd> <kbd>K</kbd> or <kbd>Ctrl</kbd> <kbd>K</kbd> to search your tables and settings. [Find your way around](/admin-navigation) has the full tour and what moved.

![Table editor with numbered badges on its six tabs: 1 Table Rows, 2 Custom Filter, 3 Table Design, 4 Table Configuration, 5 Frontend Editing, 6 Custom CSS/JS](/images/getting-started/ninja-tables-introduction/2.-Editor-Tabs-Numbered.webp)

1. **Table Rows**: add rows, set up columns, import and export.
2. **Custom Filter** (Pro): dropdown, checkbox, date and range filters above the table.
3. **Table Design**: colors, styling, search, pagination and mobile layout, with a live preview.
4. **Table Configuration**: the engine, how rows load, and caching.
5. **Frontend Editing** (Pro): let logged-in users change rows on the page. It does not show for connected tables.
6. **Custom CSS/JS**: your own CSS, or JavaScript (Pro).

## Free or Pro?

The free plugin builds, styles and publishes tables. Pro adds live data sources and power tools.

| Free | Pro adds |
|---|---|
| Default, Upload a file, Drag & Drop, Fluent Forms and FluentCart tables | WP Posts, WooCommerce products and reviews, Google Sheets, Remote CSV, Custom SQL |
| Table Design presets, fonts, search, sorting, pagination, mobile layout | Custom colors, sticky header and first column, export and print buttons |
| Text, number, date and HTML columns | Conditional formatting, Transform and formulas, Select, Image and Button columns |
| Shortcode, block, Custom CSS | Custom filters, Frontend editing, Custom JS, Permissions |

Full list: [Free vs Pro](/free-vs-pro).

## Common questions

Short answers, each with the guide to read next.

::: faq
== Do I need Pro?
Not to get started. The free plugin covers tables you type in, upload from a file or build in Drag & Drop, plus Fluent Forms and FluentCart tables. See [Free vs Pro](/free-vs-pro).
== Will my tables work on phones?
Yes. You can hide columns on small screens, or [stack each row as a card](/stackable-table).
== FooTable or DataTables?
New tables use DataTables by default, which holds up well for thousands of rows. You can switch a new table to FooTable with **Change**. Tables that store their own rows keep the engine they were created with, so read [FooTable or DataTables](/choose-table-engine) before you build a large table.
== Do tables slow my site down?
On the free plugin, rows load with Ajax right after the page, and table data is cached. With Pro active, new tables default to Legacy rendering instead, which builds the rows into the page. See [Engine, rendering & caching](/table-rendering-settings).
== Are tables accessible and SEO-friendly?
Tables are built to meet WCAG 2.1 AA, and you can give each one a caption in its [title and description settings](/table-title-description-settings). Ninja Tables outputs clean HTML tables; Legacy rendering (Pro) puts every row in the page HTML.
== Where did a screen go after the update?
[Find your way around](/admin-navigation) has a map of where older screens moved.
== Can I move my tables from TablePress?
Yes, in one click from the **Import** screen. See [Import from TablePress](/import-table-from-tablepress-plugin).
:::
