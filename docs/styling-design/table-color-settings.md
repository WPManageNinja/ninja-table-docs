# Table Colors

**Table colors** control the search bar, header, body rows, hover state and footer of a table. Pick a ready-made scheme or set each color yourself. The **Default** scheme is free; the other schemes and **Custom** colors are Pro.

1. Go to **Ninja Tables** › **Tables** and open a table.
2. Click the **Appearance** tab.
3. In the settings panel, click the **Colors** tab. It is the tab the panel opens on.

![Colors tab showing the Preset and Custom mode choices and the scheme swatches](/images/styling-design/table-color-settings/1.-Colors-Tab-Showing-The-Preset.webp)

At the top, **Color Mode** has two choices: **Preset** and **Custom** (Pro).

## Preset: ready-made color schemes

With **Preset** selected, click a swatch to pick a **Color Scheme**. The preview updates straight away, and the name of the chosen scheme shows above the swatches. There are 14 schemes:

**Default**, **White**, **Red**, **Orange**, **Yellow**, **Olive**, **Green**, **Teal**, **Blue**, **Violet**, **Purple**, **Pink**, **Grey** and **Black**.

**Default** adds no colors, so the table follows your theme and style library. It is the only scheme on the free version; clicking any other swatch opens the upgrade popup.

![Preset color schemes with the Blue scheme selected and the table preview in blue](/images/styling-design/table-color-settings/2.-Preset-Color-Schemes-With-The-Blue.webp)

## Custom: set each color (Pro)

Select **Custom** and set each color yourself. Leaving a field empty keeps the default. Switching back to **Preset** uses the scheme again.

Editing any custom color switches the table to **Custom** mode automatically, so the color you set takes effect without you touching the mode.

![Custom color sections for search bar, header, body and footer](/images/styling-design/table-color-settings/3.-Custom-Color-Sections-For-Search-Bar.webp)

- **Search Bar Colors**: **Background**, **Icon** and **Border** of the search box.
- **Table Header Colors**: **Background**, **Text** and **Border** of the header row.
- **Table Body Colors**: **Background**, **Text** and **Border** of the rows. Use the **Default** / **Hover** switch to set the colors for normal rows and for rows under the pointer.
- **Use Alternate Color Schema For Table Rows**: off by default. Turn it on to color **Odd Row Colors** and **Even Row Colors** separately (zebra striping). Each has a **Background**, a **Text** color and a **Hover Background**.
- **Footer Colors**: **Background**, **Active** and **Border** of the pagination bar. These are the same colors as **Pagination** › **Colors**, so a change in one shows in the other.

::: tip
A custom border color only shows when the table has borders. Turn on **Bordered Table** under **Style** › **Rows & Borders**.
:::

## What the free version does

On the free version, clicking a paid scheme, **Custom** or a color field opens the upgrade popup and changes nothing. If a table still holds paid colors, they are reset to the **Default** scheme when you save.

Click **Save** to keep your colors.
