# Table Colors

**Table colors** control the search bar, header, body rows, hover state and footer of a table. Pick a ready-made scheme or set each color yourself. Color schemes and custom colors are a Pro feature; on the free version the preview shows them, but they are not saved.

## Open the color settings

1. Go to **Ninja Tables** › **Tables** and open a table.
2. Click the **Appearance** tab.
3. In the settings panel, click the **Colors** tab.

![Table color options](/images/styling-design/table-color-settings/1.-New-Ui-table-color-options.webp)

At the top, **Color mode** has two choices: **Preset** and **Custom**.

## Preset: ready-made color schemes

With **Preset** selected, pick a **Color scheme** from the list. The preview updates straight away. The default scheme adds no colors, so the table follows your theme and style library.

![Predefined color scheme](/images/styling-design/table-color-settings/2.-New-Ui-predefined-color-scheme.webp)

## Custom: set each color (Pro)

Select **Custom** and set each color yourself. Switching back to **Preset** uses the scheme again.

![Custom color settings](/images/styling-design/table-color-settings/3.-New-ui-custom-color-settings.webp)

- **Search Bar Colors**: background, icon and border of the search box.
- **Table Header Colors**: background, text and border of the header row.
- **Table Body Colors**: the colors of the rows. Use the **Row state** switch to set colors for **Default** rows and for rows on **Hover**.
- **Use alternate color schema for table rows**: turn this on to color **Odd Row Colors** and **Even Row Colors** separately (zebra striping), each with its own hover background.
- **Footer Colors**: the pagination area, including the **Active** page.

::: tip
A custom border color only shows when the table has borders. Turn on a bordered style under **Style** › **Rows & borders**.
:::

Click **Save** to keep your colors.
