# Appearance Tab Overview

The **Appearance** tab is where you design how a table looks and behaves on your site. It shows a live preview of the table on the left and a settings panel on the right, so you see every change before you save it.

To open it, go to **Ninja Tables** › **Tables**, open a table, and click the **Appearance** tab.

![Appearance tab](/images/styling-design/table-style-settings/1.-New-Ui-table-design-tab.webp)

## The live preview

The preview is rendered by your active theme, exactly as visitors will see it, including your theme's fonts and styles, stacked rows and filters. Unsaved changes show in the preview until you save or leave the page.

- **Preview width**: switch between **Desktop**, **Tablet** and **Mobile** to check how the table looks on each screen size.
- **Hide panel** (the arrow at the top of the panel) gives the preview the full width. Click **Show panel** to bring the settings back.

Click **Save** at the top of the editor to keep your changes.

::: tip
The preview needs at least one column. If the table has no columns yet, add them in [Table Rows](/working-in-table-rows) first.
:::

## The settings panel

The panel has three tabs.

### Colors

Pick a ready-made color scheme, or set every color yourself with a **Custom** scheme (Pro). See [Table Colors](/table-color-settings).

### Style

- **Title & header**: show or hide the table title, the table description and the header row. See [Table Title, Caption & Description](/table-title-description-settings).
- **Typography**: font family and font size. See [Fonts](/table-font-settings).
- **Rows & borders**:
  - **Style library**: **Semantic UI**, **Bootstrap 4** or **Bootstrap 3**. The options below it depend on the library you pick. Semantic UI suits most sites; pick Bootstrap only if your theme already uses it. This choice is only shown for tables on the FooTable engine.
  - **Quick styles**: one-click presets: **Minimal**, **Lined**, **Striped**, **Bordered** and **Compact**.
  - Individual switches such as hover rows, bordered table, striped rows, compact table, single line cells and vertically centered cells. Each one has a short description under it.

### Features

- **Search**: the search box, its texts, position and colors. See [Search Box](/add-or-remove-search-or-filter-functionality).
- **Sorting**: let visitors sort by clicking a column heading, and set the default order. See [Sorting](/sorting).
- **Pagination**: rows per page, page-size changer and position. See [Pagination](/pagination).
- **Sticky header & column** (Pro): see [Sticky Header & First Column](/other-design-settings).
- **Mobile & row details**: stack rows as cards or fold columns into a **+** drawer, and the row details popup. See [Mobile View](/stackable-table).
- **Export & print** (Pro): download and print buttons for visitors. See [Export & Print Buttons](/csv-and-print-button).

Sections with a switch in their heading (Search, Sorting, Pagination) can be turned on or off as a whole.

## Use this design for new tables

At the bottom of the panel, **Use as default for new tables** saves this table's design as the starting point for every table you create next. See [Use a Design as the Default](/use-design-as-default).
