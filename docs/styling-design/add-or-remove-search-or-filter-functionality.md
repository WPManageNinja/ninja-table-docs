# Search Box

The **search box** above a table lets visitors type a word and see only the rows that contain it. You can turn it on or off, change its texts, and decide where it sits.

1. Go to **Ninja Tables** › **Tables** and open a table.
2. Click the **Appearance** tab, then the **Features** tab in the settings panel.
3. Open **Search**.

![Search settings](/images/styling-design/remove-search-filter/1.-New-Ui-enable-filter-and-search.webp)

The switch in the **Search** heading turns the search box on or off.

## Texts

These replace the old **Language settings**:

- **Placeholder text**: the grey hint inside the empty search box (default: `Search...`).
- **Empty Result Text**: the message shown when nothing matches (default: `No Result Found`).
- **Dropdown Heading**: the heading of the "search in" dropdown that lets visitors pick which columns to search (default: `Search in`).

## Look

- **Position** (Pro): **Left**, **Center**, **Right** or **Default**.
- **Full width** (Pro): the search box takes the full width above the table.
- **Colors** (Pro): background, icon and border of the search box.

Click **Save** to keep your changes.

## Leave a column out of the search

By default every column is searched. To leave one out, open the column's settings in **Table Rows**, go to the **Advanced** tab and turn off **Searchable** (Pro). See [Advanced Column Options](/advanced-settings).

![Searchable column option](/images/styling-design/remove-search-filter/2.-New-Ui-enable-sorting-filtering.webp)

## Need dropdown filters?

The search box searches text. To give visitors dropdowns, checkboxes or date and number ranges, use [Custom Filters](/custom-filters) (Pro).
