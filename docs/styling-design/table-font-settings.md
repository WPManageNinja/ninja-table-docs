# Table Fonts

The **Typography** settings change the font family and font size used in a table, so it matches your site or stands out from it. They are free.

1. Go to **Ninja Tables** › **Tables** and open a table.
2. Click the **Appearance** tab, then the **Style** tab in the settings panel.
3. Open **Typography**.

- **Font Family**: pick a font from the list. The default, **Inherit From Theme**, uses your theme's font. The other choices are generic families your visitors' devices provide: **Sans-Serif**, **Serif**, **Monospace**, **System UI**, **UI Sans-Serif**, **UI Serif**, **UI Monospace**, **UI Rounded**, **Cursive** and **Fantasy**.
- **Font Size**: drag the slider from 8 to 50 px. The default is 14 px.

Check the result in the preview, then click **Save** to keep your changes.

::: tip
To set the font for every new table, use the gear icon › **Settings** › **Global appearance**. See [Default Design for New Tables](/use-design-as-default).
:::
