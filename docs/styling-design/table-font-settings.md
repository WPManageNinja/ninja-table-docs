# Table Fonts

The **Typography** settings change the font family and font size used in a table, so it matches your site or stands out from it.

1. Go to **Ninja Tables** › **Tables** and open a table.
2. Click the **Appearance** tab, then the **Style** tab in the settings panel.
3. Open **Typography**.

![Typography settings](/images/styling-design/table-font-settings/1.-New-Ui-table-design-Other-tab.webp)

- **Font family**: pick a font from the list. The default, **Inherit from theme**, uses your theme's font.
- **Font size**: drag the slider (8 to 50 px). The default is 14 px.

Check the result in the preview, then click **Save**.

::: tip
To set the font for every new table, use the gear icon › **Settings** › **Global appearance**, or [use one table's design as the default](/use-design-as-default).
:::
