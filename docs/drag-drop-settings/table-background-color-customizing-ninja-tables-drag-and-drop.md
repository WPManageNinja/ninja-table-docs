# Table Background Color (Drag & Drop)

The old **Background** mode in the Drag & Drop builder is gone. Header, even-row, odd-row and selected cell, row and column colors are now set by clicking a cell and using the **Settings** tab. See [Drag & Drop Cell Settings](/drag-drop-cell-settings).
