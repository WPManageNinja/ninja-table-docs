# Table Background Color (Drag & Drop)

The old **Background** mode in the Drag & Drop builder is gone. Header, even-row and odd-row colors are now in the table settings, under **Background** (click outside the table, then open the **Settings** tab). Colors for one cell, a row or a column are set by selecting it, then using the **Settings** tab. See [Table Settings](/ninja-tables-drag-and-drop-table-settings) and [Cell Settings](/drag-drop-cell-settings).
