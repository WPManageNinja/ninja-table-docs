# Drag & Drop Mobile & Tablet Layout

On phones and tablets, a wide Drag & Drop table is hard to read. The **responsive** settings stack the table's cells into groups on smaller screens, so each column becomes a readable block.

To find them, click outside the table in the builder so nothing is selected, then scroll down the **Settings** tab to **Responsive**, **Mode options** and **Responsive settings**.

![Responsive settings](/images/drag-drop-settings/responsive-table-design/1.-responsiveness.webp)

Check the result with the **Desktop**, **Tablet** and **Mobile** buttons in the canvas toolbar. In tablet and mobile view you can only look; switch back to **Desktop** to edit.

## Responsive

- **Enable responsive table**: turns the responsive layout on. It is on for new tables, but some [templates](/drag-drop-templates) start with it off, so they keep their desktop layout on phones.

![Enable responsive table](/images/drag-drop-settings/responsive-table-design/2.-Responsivenss-of-a-table.webp)

## Mode options

Choose **Mobile** or **Tablet** and set how the table stacks on that device:

- **Disable breakpoint**: keep the normal table layout on this device.
- **Cell stack direction**: stack cells as a **Row** or a **Column**.
- **Top row as header**: repeat the first row as a heading in each stacked group (on by default).
- **Items per header**: how many columns share one header group (1–5; default 1 on mobile and 2 on tablet).
- **Group separator**: the space between stacked groups (1–10, default 5).

The **Desktop** tab shows two options that can't be changed; desktop always uses the normal layout.

![Mode options for mobile](/images/drag-drop-settings/responsive-table-design/3.-Enable-responsiveness-on-mobile.webp)

## Responsive settings

For **Mobile** and **Tablet** separately:

- **Cell padding**: space inside each cell on that device.
- **Table alignment**: **Left**, **Center** or **Right** on that device.

![Responsive settings for mobile and tablet](/images/drag-drop-settings/responsive-table-design/5.-table-responsiveness-on-mobile-and-table.webp)
