# Drag & Drop Cell Settings

**Cell settings** control the colors and size of the cells in a Drag & Drop table: colors for every row, colors for a selected row, column or cell, a highlighted column (Pro), and row height and column width.

To open them, click a cell in the builder. The **Settings** tab of the right panel shows **Settings · Cell**.

![Cell settings](/images/drag-drop-settings/manage-cells-ninja-tables/3.-Select-a-table-cell-to-edit.webp)

## Colors for every row

- **Header background**
- **Even row background**
- **Odd row background**

These are the same as **Table** › **Background** in the [table settings](/ninja-tables-drag-and-drop-table-settings).

![Row colors](/images/drag-drop-settings/table-background-color/2.-Table-row-color-odd-and-even.webp)

## Colors for what you picked

Color only the row, column or cell you selected:

- **Selected cell row background**
- **Selected cell column background**
- **Selected cell background**

Hold **Shift** and click to select several cells and color them at once. Each color picker also has an opacity slider.

![Selected cell colors](/images/drag-drop-settings/table-background-color/4.-selected-cell-in-tables.webp)

## Highlight column (Pro)

Make one column stand out, as in a "most popular" pricing plan. Turn on **Highlight column** and set:

- **Highlighted column height**
- **Shadow color**
- **Shadow effect (X-axis)**, **(Y-axis)** and **(blur radius)**

![Highlighted column](/images/drag-drop-settings/manage-cells-ninja-tables/4.-highlight-table-column-2.webp)

## Row height and column width

- **Row height**: the height of the selected cell's row (default 50).
- **Column width**: the width of the selected cell's column (default 150).

To merge or split cells, use **Merge** and **Split** in the canvas toolbar; see [Rows & Columns](/drag-drop-rows-columns).

Click **Save** to keep your changes.
