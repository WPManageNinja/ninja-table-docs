# Button Element

The **Button** element adds a clickable button to a Drag & Drop table cell, such as "Buy now" in a pricing table. Each button has its own link, colors, size, optional icon and hover effect. The button is free; adding an icon to it needs Pro.

To add one, click a cell and click **Button** in the **Elements** tab. Click the button to set its options in the **Settings** tab, which has four sub-tabs.

## General

- **Label**: the button text.
- **Background color**, **Border color**, **Border size** and **Border radius**.
- **Full width**: stretch the button across the cell. When off, choose **Button size** (**S**, **M** or **L**) and **Alignment**.
- **URL**: where the button links to.
- **Link rel attributes**: add `sponsored`, `nofollow`, `noreferrer` or `noopener`, for example for affiliate links.
- **Open in a new tab**

## Text

- **Font color**, **Font size** and **Font style**.

![Button text options](/images/drag-drop-elements/button-element/2.-ninja-tables-Button-Text-1.webp)

## Icon (Pro)

- **Enable icon**
- **Icon color**, **Icon size** and **Item spacing** (space between icon and text).
- Pick an icon, using **Search icons**, or **Upload your own**.
- **Icon position**: left or right of the text.

![Button with icon](/images/drag-drop-elements/button-element/3.-Button-with-icon.webp)

## Hover

Turn on **Button hover** to change the button when a visitor points at it:

- **Background color**, **Text color**, **Icon color**, **Border color** and **Border size** on hover.
- **Scale**: grow or shrink the button slightly on hover.

![Button hover options](/images/drag-drop-elements/button-element/4.-Button-hover.webp)

Below the sub-tabs, **Spacing** sets the margin and padding around the button; see [Element Spacing](/spacing).

Click **Save** to keep your changes.
