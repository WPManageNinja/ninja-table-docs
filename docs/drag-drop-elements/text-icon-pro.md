# Text Icon Element (Pro)

The **Text Icon** element (Pro) shows a short piece of text with an icon beside it, such as a phone icon next to a number or a clock next to opening hours. On the free version the tile has a **PRO** badge, and clicking it shows "You are using free version of ninja-tables, Upgrade To Pro" and adds nothing.

To add one, click a cell and click **Text Icon** in the **Advanced** group of the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. The name changes by place: the tile says **Text Icon**, the chip in the cell says "Text with icon" and the Settings tab says "Text icon". Click it to set its options in the **Settings** tab, which has three sub-tabs: **General**, **Text** and **Icon**.

## General

- **Text** (default "Enter text..."): the text to show.
- **Item spacing** (0–200, default 0): the space between the icon and the text.
- **Alignment**: **Left**, **Center** (default) or **Right**.

## Text

- **Font color**, **Font size** (10–50) and **Font style** (bold, italic, underline, strikethrough).

## Icon

- **Color**: the icon's color. Only shown when the icon is an SVG; an uploaded PNG or JPG keeps its own colors.
- **Icon size** (10–50).
- **Icon**: pick one from the library with the search box, or click **Upload your own** to choose an image from the media library. The default icon is "ninja-table".
- **Icon position**: left or right of the text.
