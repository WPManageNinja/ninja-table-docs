# HTML Element

The **HTML** element lets you write your own HTML in a Drag & Drop table cell, for content no other element covers, such as an embedded video, a custom badge or a small form. It is free. In the Settings tab it is titled **Custom HTML**.

To add one, click a cell and click **HTML** in the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. It starts with a centered "custom html" placeholder. Click it and type your HTML in the code box ("write html") in the **Settings** tab, or edit it on the canvas.

The element only has the code box and [spacing](/spacing). Style the content with inline styles or classes in your HTML, or with the table's **Custom CSS** in the [table settings](/ninja-tables-drag-and-drop-table-settings). Some HTML may be filtered when you click **Save**, so check the result in **Preview**.

Click **Save** to keep your changes.

::: tip
To show the output of a shortcode, use the [Shortcode element](/shortcode-element) instead.
:::
