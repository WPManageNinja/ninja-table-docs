# HTML Element

The **HTML** element lets you write your own HTML in a Drag & Drop table cell, for content no other element covers, such as an embedded video, a custom badge or a small form. In the Settings tab it is called **Custom HTML**.

To add one, click a cell and click **HTML** in the **Elements** tab. Click it and type your HTML in the code box in the **Settings** tab.

![HTML element in a table](/images/drag-drop-elements/html-element/1.-HTML-element-in-table.webp)

The element only has the code box and [spacing](/spacing). Style the content with inline styles or classes in your HTML, or with the table's **Custom CSS** in the [table settings](/ninja-tables-drag-and-drop-table-settings).

Click **Save** to keep your changes.

::: tip
To show the output of a shortcode, use the [Shortcode element](/shortcode-element) instead.
:::
