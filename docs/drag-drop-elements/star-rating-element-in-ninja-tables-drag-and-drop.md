# Rating Element

The **Rating** element shows a star rating in a Drag & Drop table cell, for example to rate products or plans. It is free. In the Settings tab it is titled **Star rating**.

To add one, click a cell and click **Rating** in the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. The new rating starts at 5 stars. Click the stars on the canvas to set the score (half stars are allowed); the score is not in the Settings panel. Click the element to set its other options in the **Settings** tab.

## Rating options

Under **Content & style**:

- **Star size** (10–50, default 20).
- **Alignment**: **Left**, **Center** (default) or **Right**.
- **Color** (default `#F2C009`): the color of the filled stars.
- **Show rating value** (off by default): show the score next to the stars, for example "4.5/5".
- **Maximum star** (3–10, default 5): the total number of stars.

Below the options, **Spacing** sets the margin and padding around the rating; see [Element Spacing](/spacing).

Click **Save** to keep your changes.
