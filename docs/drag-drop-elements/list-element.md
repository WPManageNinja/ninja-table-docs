# List Element

The **List** element adds a bulleted or numbered list to a Drag & Drop table cell, for example the features included in a pricing plan. It is free.

To add one, click a cell and click **List** in the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. The list starts with three items ("list item 1", "list item 2", "list item 3"). Click the list to set its options in the **Settings** tab, under **Content & style**. It is one scrolling panel with four sections: **Content**, **General**, **Text** and **List**.

![List element in a Drag & Drop table cell](/images/drag-drop-elements/list-element/1.-List-Element-In-A-Drag-Drop.webp)

## Content

Type your list in the **Items** box, one item per line. A new line adds an item and deleting a line removes it.

![List Items box with one item per line](/images/drag-drop-elements/list-element/4.-List-Items-Box.webp)

You can also edit on the canvas. Click an item in the cell to change its text, hover over it and click its **copy** icon to add another item, or its **delete** icon to remove it. These icons only show in the Desktop preview.

![List item with the copy and delete icons showing](/images/drag-drop-elements/list-element/2.-List-Item-With-The-Copy.webp)

## General

- **Item Spacing Vertically**: the space between items. The minimum is the table's global font size minus 2, the maximum is 50, and the default is 20.
- **Space Between Icon And Text** (−5 to 100, default 0): the gap between the bullet or number and the text.
- **Alignment**: **Left**, **Center** (default) or **Right**.

## Text

- **Font Color**, **Font Size** (10–50) and **Font Style** (**Bold**, **Italic**, **Underline**, **Strikethrough**).

## List

- **List Type**: **Unordered List** (bullets, default) or **Ordered List** (numbers or letters). Switching the type resets **List Icon** to the first choice.
- **List Icon**: the marker style. For an unordered list: **circle** (default), **square**, **disc** or **none**. For an ordered list: **upper-roman**, **lower-roman**, **upper-alpha**, **lower-alpha** or **decimal**.

![List section with the list type and list icon options](/images/drag-drop-elements/list-element/3.-List-Sub-Tab-With-The-List.webp)

Under **Content & style**, the **Spacing** section sets the margin and padding around the list; see [Element Spacing](/guide/drag-drop-settings/spacing).

Click **Save** to keep your changes.

Want your own icons instead of bullets? Use the [Styled List](/guide/drag-drop-elements/styled-list) element (Pro).
