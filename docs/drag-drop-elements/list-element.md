# List Element

The **List** element adds a bulleted or numbered list to a Drag & Drop table cell, for example the features included in a pricing plan.

To add one, click a cell and click **List** in the **Elements** tab. Type the items in the cell, then click the list to set its options in the **Settings** tab, which has three sub-tabs.

## General

- **Item spacing vertically**: space between list items.
- **Space between icon and text**: space between the bullet or number and the text.
- **Alignment**: left, center or right.

![List general options](/images/drag-drop-elements/list-element/1.-List-element-general-options.webp)

## Text

- **Font color**, **Font size** and **Font style**.

![List text options](/images/drag-drop-elements/list-element/2.-list-element-custom-text.webp)

## List

- **List type**: **Unordered** (bullets) or **Ordered** (numbers or letters).
- **List icon**:
  - Unordered: **circle**, **square**, **disc** or **none**.
  - Ordered: **decimal**, **upper-alpha**, **lower-alpha**, **upper-roman** or **lower-roman**.

![Ordered list](/images/drag-drop-elements/list-element/3.-ordered-list-element.webp)

Below the sub-tabs, **Spacing** sets the margin and padding around the list; see [Element Spacing](/spacing).

Want icons instead of bullets? Use the [Styled List](/styled-list) element (Pro).
