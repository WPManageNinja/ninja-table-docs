# Styled List Element (Pro)

The **Styled List** element (Pro) is a list that uses an icon of your choice instead of a bullet, such as a check mark in front of each feature in a pricing plan. In the Settings tab it is titled "Stylist List" (the plugin's spelling). On the free version the tile has a **PRO** badge, and clicking it shows "You are using free version of ninja-tables, Upgrade To Pro" and adds nothing.

To add one, click a cell and click **Styled List** in the **Advanced** group of the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. The list starts with three items. Click the list to set its options in the **Settings** tab, which has three sub-tabs: **General**, **Text** and **Icon**.

![Styled List element with check mark icons](/images/drag-drop-elements/styled-list/1.-Styled-List-Element-With-Check-Mark.webp)

## Add and remove items

Click an item to edit its text. Styled List has no **Items** box (unlike [List](/guide/drag-drop-elements/list-element)), so edit on the canvas. Hover over an item and click its **copy** icon to add another item, or its **delete** icon to remove it. These icons only show in the Desktop preview.

## General

- **Space Between Icon And Text** (0–200).
- **Item Spacing Vertically**: the space between items. The minimum is the table's global font size minus 2, the maximum is 50.
- **Alignment**: **Left**, **Center** (default) or **Right**.

## Text

- **Font Color**, **Font Size** (10–50) and **Font Style** (**Bold**, **Italic**, **Underline**, **Strikethrough**).

## Icon

- **Icon Color**: only shown when the icon is an SVG. An uploaded PNG or JPG keeps its own colors.
- **Icon Size** (10–50).
- **Icon**: pick one from the library with **Search Icons**, or click **Upload Your Own** to choose an image from the media library. The default icon is "heart".

![Styled List Icon sub-tab with the icon picker](/images/drag-drop-elements/styled-list/2.-Styled-List-Icon-Sub-Tab.webp)

Under **Content & style**, the **Spacing** section sets the margin and padding around the list; see [Element Spacing](/guide/drag-drop-settings/spacing). Click **Save** to keep your changes.

For a plain bulleted or numbered list, use the free [List element](/guide/drag-drop-elements/list-element).
