# Styled List Element (Pro)

The **Styled List** element (Pro) is a list that uses an icon of your choice instead of a bullet, such as a check mark in front of each feature in a pricing plan. In the Settings tab it is called "Stylist list".

To add one, click a cell and click **Styled List** in the **Advanced** group of the **Elements** tab. Type the items, then click the list to set its options in the **Settings** tab, which has three sub-tabs.

## General

- **Space between icon and text**
- **Item spacing vertically**: space between list items.
- **Alignment**: left, center or right.

![Styled list general options](/images/drag-drop-elements/styled-list/1.-Styled-list-drag-and-drop.webp)

## Text

- **Font color**, **Font size** and **Font style**.

![Styled list text options](/images/drag-drop-elements/styled-list/2.-Styled-List-element.webp)

## Icon

- **Icon color** and **Icon size**.
- Pick an icon, using the search box, or **Upload your own**.

![Styled list icon options](/images/drag-drop-elements/styled-list/3.-Stylied-list-icon.webp)

Below the sub-tabs, **Spacing** sets the margin and padding around the list; see [Element Spacing](/spacing). Click **Save** to keep your changes.

For a plain bulleted or numbered list, use the free [List element](/list-element).
