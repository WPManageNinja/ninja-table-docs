# Image Element (Pro)

The **Image** element (Pro) adds a picture to a Drag & Drop table cell, such as a product photo, a team member's portrait or a logo. The image can also link somewhere. On the free version the **Image** tile has a **PRO** badge, and clicking it shows "You are using free version of ninja-tables, Upgrade To Pro" and adds nothing.

To add one, click a cell and click **Image** in the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. The new element starts with a demo image. Click it to set its options in the **Settings** tab.

## Image options

Under **Content & style**:

- **Replace image**: opens the media library ("Choose Image") so you can pick your own picture.
- **Alignment**: **Left**, **Center** (default) or **Right**.
- **Image size** (10–100, default 50): the width of the image as a percentage of the cell.
- **Image shape**: **Square** or **Round** (a circle).
- **Image alternative text** (default "Demo Image"): describes the image for screen readers and search engines. Change it to describe your picture.
- **Image link**: make the image clickable. Empty by default.
- **Open in a new tab**: off by default, unlike the Button element.
- **Link rel attributes**: tick `sponsored`, `nofollow`, `noreferrer` or `noopener`.
