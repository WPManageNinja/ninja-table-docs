# Image Element (Pro)

The **Image** element (Pro) adds a picture to a Drag & Drop table cell, such as a product photo, a team member's portrait or a logo. The image can also link somewhere.

To add one, click a cell and click **Image** in the **Elements** tab. Click the image to set its options in the **Settings** tab.

![Image element in a table](/images/drag-drop-elements/image-element/1.-Image-element-in-tables.webp)

## Image options

- **Replace image**: choose a different image from the media library.
- **Alignment**: left, center or right.
- **Image size** (10–100, default 50).
- **Image shape**: **Square** or **Round**.
- **Image alternative text**: describe the image for screen readers and search engines.
- **Image link**: make the image clickable.
  - **Open in a new tab**
  - **Link rel attributes**: `sponsored`, `nofollow`, `noreferrer` or `noopener`.
- **Spacing**: margin and padding around the image. See [Element Spacing](/spacing).

![Images in a table](/images/drag-drop-elements/image-element/2.-Images-in-data-table.webp)

Click **Save** to keep your changes.
