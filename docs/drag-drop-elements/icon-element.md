# Icon Element (Pro)

The **Icon** element (Pro) shows a single icon in a Drag & Drop table cell. It is handy for comparison tables, where a check mark or a cross says more than words. On the free version the **Icon** tile has a **PRO** badge, and clicking it shows "You are using free version of ninja-tables, Upgrade To Pro" and adds nothing.

To add one, click a cell and click **Icon** in the **Elements** tab. If no single cell is selected, it goes into the last (bottom-right) cell. Click the icon to set its options in the **Settings** tab.

## Icon options

Under **Content & style**:

- **Color** (default `#000000`): the icon's color. Only shown when the icon is an SVG; an uploaded PNG or JPG keeps its own colors.
- **Icon size** (10–150): 10 uses the table's global font size.
- **Alignment**: **Left**, **Center** (default) or **Right**.
- **Icon**: pick one from the library with the search box, or click **Upload your own** to choose an image from the media library. The default icon is "ninja-table".

Click **Save** to keep your changes.
