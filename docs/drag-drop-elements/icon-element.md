# Icon Element (Pro)

The **Icon** element (Pro) shows a single icon in a Drag & Drop table cell. It's handy for comparison tables, where a check mark or a cross says more than words.

To add one, click a cell and click **Icon** in the **Elements** tab. Click the icon to set its options in the **Settings** tab.

![Icon element in a table](/images/drag-drop-elements/icon-element/1.-Icon-element-in-table.webp)

## Icon options

- **Color**: the icon's color.
- **Icon size** (10–150).
- **Alignment**: left, center or right.
- **Icon**: pick one from the library, using the search box to find it, or click **Upload your own**. An SVG you upload takes the color above; a PNG or JPG keeps its own colors.
- **Spacing**: margin and padding around the icon. See [Element Spacing](/spacing).

Click **Save** to keep your changes.
