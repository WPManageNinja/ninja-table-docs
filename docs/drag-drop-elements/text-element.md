# Text Element

The **Text** element holds a heading, a price, a label or a paragraph in a Drag & Drop table cell. It's the most used element; every cell of a table created from scratch starts with an empty Text element.

## Add text

1. In the builder, click a cell.
2. In the **Elements** tab, click **Text** (or drag it onto the cell).
3. Click the text in the cell and start typing.

![Drag the Text element onto a cell](/images/drag-drop-elements/text-element/1.-Drag-cell-element.webp)

While you type in the cell, a small toolbar offers **bold**, **italic**, **underline**, **strikethrough**, **link** and **unlink**.

## Text options

Click the Text element and open the **Settings** tab:

- **Content**: the text itself. Switch between **Visual** and **HTML** to edit it as formatted text or as HTML.
- **Font color**
- **Font size** (10–45). By default the table's global font size is used (15).
- **Alignment**: left, center or right.
- **Font style**: bold, italic, underline or strikethrough.
- **Spacing**: margin and padding around the text. See [Element Spacing](/spacing).

![Text element options](/images/drag-drop-elements/text-element/2.-Customize-table-cell-element.webp)

Click **Save** to keep your changes.

::: tip
To set the default font, size and color for the whole table, use **Global style** in the [table settings](/ninja-tables-drag-and-drop-table-settings).
:::
