# Drag & Drop Templates

**Templates** give you a finished Drag & Drop table design to start from, so you only change the text, prices and links. There are 20 templates in six categories; 9 are free and the other 11 need Ninja Tables Pro.

## Use a template

1. Go to **Ninja Tables** › **Create Table** › **Drag & Drop table**.
2. Under **Choose a Template**, filter by category (**All**, **Pricing**, **Comparison**, **Employee**, **Schedule**, **Specification** or **Stats**).
3. Hover a template for a larger preview, then click it to select it.
4. Click **Next**. Check the **Table Name**, which is pre-filled from the category (for example "Pricing table").
5. Click **Create Table**.

![Template picker showing template cards with the Pricing category selected](/images/drag-drop-tables/drag-drop-templates/1.-Template-Picker-Showing-Template-Cards.webp)

The table opens in the builder, where you can change everything. Its shortcode works straight away, because a template table saves its design once when it's created. See [Create a Drag & Drop Table](/guide/drag-drop-tables/how-to-create-your-first-drag-and-drop-table-with-ninja-tables).

## Available templates

| Category | Free | Pro |
|---|---|---|
| **Pricing** | Pricing Table One | Pricing Table Two, Three, Four |
| **Comparison** | Comparison Table One | Comparison Table Two, Three, Four, Five |
| **Employee** | Employee Table One | Employee Table Two, Three |
| **Schedule** | Schedule Table One, Two, Three, Opening Hours | None |
| **Specification** | Spec Sheet | Product Specs |
| **Stats** | Leaderboard | Stats Dashboard |

Comparison Table Four includes a highlighted column, set with **Highlight column** in [Cell Settings](/guide/drag-drop-settings/drag-drop-cell-settings).

## Pro templates

Pro templates carry a **PRO** badge. The badge shows on these cards even when Ninja Tables Pro is active, so it marks which templates are Pro, not which are locked.

On the free version, clicking a Pro template shows "This is a Pro feature." and opens the upgrade page in a new tab. It isn't selected and nothing is created.

::: tip
Every template comes with **Enable Responsive Table** turned on, but several have **Use Top Row As Header** turned off for mobile or tablet. Check the **Responsive** tab if a template does not stack the way you expect; see [Mobile & Tablet Layout](/guide/drag-drop-settings/responsive-table-design).
:::
