# Create a Drag & Drop Table

The **Drag & Drop table** builder lets you design a table visually, cell by cell. Instead of rows of data, each cell can hold elements such as text, buttons, icons, star ratings, lists or images. It's ideal for pricing tables, feature comparisons, team lists and schedules.

## Create the table

1. Go to **Ninja Tables** › **Create Table**.
2. Under **Start from scratch**, click **Drag & Drop table**.
3. Enter a **Table name** (for example "Pricing plans"). When importing a file, you can leave it empty; the table is named after the file.
4. Under **Start with**, pick one of:
   - **Create From Scratch**: an empty grid.
   - **Import from CSV/JSON**: build the table from a file.
   - **Choose a template**: start from a ready-made design.
5. Click **Next**.

![Drag & Drop table creation](/images/drag-drop-tables/create-first-drag-drop/3.-New-UI-drag-and-drop-table.webp)

### From scratch

Set the number of **columns** across the top and **rows** down the side, using the **−** and **+** buttons or by typing a number (1 to 30 each). The default is 6 rows × 3 columns. Click **Create table**.

![Choose rows and columns](/images/drag-drop-tables/create-first-drag-drop/4.-Add-row-columns.webp)

### From a CSV or JSON file

Drop a `.csv` or `.json` file on the upload area, or click **Browse File**. The file can be up to 1 MB. With Pro you can also import from a URL, under **From a URL**. Click **Create table**.

### From a template

Pick a category (**All**, **Pricing**, **Comparison**, **Employee** or **Schedule**), click a template, then **Create table**. See [Drag & Drop Templates](/drag-drop-templates) for the full list.

![Table templates](/images/drag-drop-tables/create-first-drag-drop/6.-Screenshot-7.webp)

The table opens in the builder.

## Build the table

1. Click a cell to select it.
2. In the right panel, on the **Elements** tab, click an element to add it to the selected cell, or drag an element onto any cell.
3. Click the element in the cell and set its options in the **Settings** tab.

![Drag an element onto a cell](/images/drag-drop-tables/create-first-drag-drop/7.-Drag-cell-element.webp)

Elements in the **General** group are **Text**, **Button**, **Icon** (Pro), **Rating**, **List**, **HTML**, **Shortcode** and **Image** (Pro). The **Advanced** group has **Styled List** (Pro), **Ribbon** (Pro), **Progress** and **Text Icon** (Pro).

![Customize a cell element](/images/drag-drop-tables/create-first-drag-drop/8.-Customize-table-cell-element.webp)

A tour of everything on the builder screen is in [Drag & Drop Builder Tour](/drag-drop-builder-tour). To add, move or merge rows and columns, see [Rows & Columns](/drag-drop-rows-columns).

## Save and add it to your site

1. Click **Save** in the top-right corner of the builder.
2. Copy the shortcode from the chip next to the table's name, for example `[ninja_table_builder id="123"]`.
3. Paste it into a page or post, or use the Ninja Tables block. See [Add a Table to Your Site](/embed-tables).

::: warning Save once before embedding
The table on your site is built from the version you last saved in the builder. A new table, including one made from a template or a file, shows only an "Edit Table" link until you click **Save** in the builder at least once.
:::

Click **Preview** in the builder to see the saved table on its own page.
