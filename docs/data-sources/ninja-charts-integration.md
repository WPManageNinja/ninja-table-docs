# Ninja Charts Integration

Charts are made with **Ninja Charts**, a free companion plugin. Go to **Ninja Tables** › **Charts** and click **Install Ninja Charts** to install it in one click. Once it is active, the same menu item opens your chart list, where **New Chart** builds a chart from one of your tables. See [Getting Started with Ninja Charts](/guide/ninja-charts/getting-started-with-ninja-charts-free-wordpress-chart-plugin) and [Create Charts with Ninja Tables Data](/guide/ninja-charts/create-ninja-charts-with-ninja-tables-data).
