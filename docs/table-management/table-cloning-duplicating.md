# Duplicate a Table

**Duplicate** makes a full copy of a table, so you can reuse its columns, rows and design as the starting point for a new one. It's quicker than building a similar table from scratch.

## Duplicate a table

1. Go to the [Tables list](/tables-list) (**Tables** in the top bar).
2. Find the table and click its **More actions** (⋯) button at the end of the row.
3. Click **Duplicate**.

Ninja Tables creates the copy and opens it straight away, in the editor (or in the Drag & Drop builder for a Drag & Drop table). The copy is named after the original with "( Duplicate )" added. Rename it with the pencil next to its name; see [Table title, caption and description](/table-title-description-settings).

## What gets copied

- The table's columns, settings and design.
- All of its rows, including tables that use the **DataTables** engine.

The copy gets its own ID and shortcode. It doesn't reuse the original's cached data, so it always shows its own rows. Changes to one table don't affect the other. The copy isn't added to any page, so **Used on** shows **Not embedded** until you embed it. See [Embed a table](/embed-tables).

::: tip
For Fluent Forms entries tables, the **More actions** menu shows a **Fluent Forms entries** link in place of **Duplicate**. It opens the form's entries in Fluent Forms.
:::
