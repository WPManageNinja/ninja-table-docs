# Rearrangement of Rows: Manual Row Sort

**Sort manually** (Pro) lets you put rows in any order you like by dragging them, instead of sorting by date or by a column. The order you set is the order visitors see on your site.

Manual sorting is available on tables that keep their own rows. Connected tables (WordPress posts, WooCommerce, Google Sheets and other sources) get their order from the source.

## Turn on manual sorting

1. Go to **Tables** › your table › **Table Rows**.
2. Click **Sort manually** in the toolbar. The button stays pressed while it is on.
3. A grip icon appears at the start of every row. Drag a row by its grip and drop it where you want it.

![Sort manually in the Table Rows toolbar](/images/table-management/rearrangement-rows-ninja/1.-01-4.webp)

Each drop is saved right away. You don't need to click Save.

Turning on **Sort manually** also sets the table's default order to **Manual**. You can see this in **Appearance** › **Sorting** › **Default order**, which you can also use to switch manual order on or off. See [Sorting](/sorting).

## While manual sorting is on

- Clicking a column name no longer sorts the grid, so the order you see is the saved order.
- When you add a row with **Add data**, the row drawer shows **Add at** so you can add the new row **First** or **Last**.
- **Insert row below** (in a row's ⋯ menu) adds a new row right under that row.
- Rows are dragged within the current page. To move a row farther, raise **Rows per page** at the bottom of the grid so both spots are on one page.

## Turn it off

Click **Sort manually** again. The table stops using the manual order. To choose another default order, such as by created date or by a column, go to **Appearance** › **Sorting**.

For more about the grid and toolbar, see [Working in Table Rows](/working-in-table-rows).
